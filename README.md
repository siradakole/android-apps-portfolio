# Android Apps Portfolio

A selection of Android apps I built in Java in 2018. The source for each app is in the public repositories linked below.

| App | What it does | Source |
|---|---|---|
| **SmartPrint** | Mobile banking app that uses the fingerprint sensor to confirm transactions: fund transfer, bill payment, airtime recharge | [gosmart24/SmartPrint](https://github.com/gosmart24/SmartPrint) |
| **ClinicCare** | Scalable app for doctors that stores data offline, retrieves patient records and syncs updates | [gosmart24/ClinicCare](https://github.com/gosmart24/ClinicCare) |
| **HealthView** | Outpatient medical app that supports incident response | [gosmart24/HealthView](https://github.com/gosmart24/HealthView) |
| **ChildGuide** | Lets parents monitor a child's phone activity: calls, SMS, browser searches and location | [gosmart24/ChildGuide](https://github.com/gosmart24/ChildGuide) |
| **MoesDailer** | Dialer for the Multiple Operator Enabled SIM (MOES) project: switches between SIMs and controls calls | [gosmart24/MoesDailer](https://github.com/gosmart24/MoesDailer) |
| **MoesTracker** | Asset tracker and tracking server built on MOES to extend network coverage | [gosmart24/MoesTracker](https://github.com/gosmart24/MoesTracker) |
| **IntelligentWalkingCain** | Bluetooth app that places calls and controls the light on a walking-cane device | [gosmart24/IntelligentWalkingCain](https://github.com/gosmart24/IntelligentWalkingCain) |

## Tech

Java, Android SDK, Bluetooth, offline data storage
